# data

Maintained data, configuration, sample, and validation artifacts for IPFS Kit Python.

This directory is part of the project’s documentation and is indexed from the
[canonical documentation map](../docs/README.md). Use the subdirectory indexes
below to find the maintained contents:

- [Configuration files](configs/README.md) — example and service configuration.
- [Sample data](samples/README.md) — data used by examples and demonstrations.
- [Test and analysis results](results/README.md) — generated or recorded validation results.

Additional maintained artifacts are organized by their purpose:

- `screenshots/` contains visual validation artifacts.
- `test_results/` contains test-run outputs and recommendations, including the
  [ARM64 support recommendations](test_results/arm64_recommendations.txt) for
  the repository's GitHub Actions workflows.
- `deprecations_report.schema.json` defines the deprecation report format.
